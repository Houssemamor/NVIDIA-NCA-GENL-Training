# NVIDIA NCA-GENL Study Hub

A lightweight web-based study hub for preparing for the NVIDIA Certified Associate: Generative AI with LLMs (NCA-GENL) exam.

## What This Project Includes

- Study mode with a quick reference sheet and practice questions
- Mock exam mode with timer, randomization, and answer review
- Progress tracking using browser `localStorage`

## Project Structure

```text
NVIDIA-NCA-GENL Training/
├── docs/
│   ├── index.html
│   ├── study.html
│   ├── exam.html
│   ├── css/
│   │   └── styles.css
│   └── js/
│       ├── questions.js
│       ├── study.js
│       └── exam.js
└── temp/
    ├── practice-exams/
    ├── reference-materials/
    ├── sample-questions/
    └── study-guides/
```

## Run Locally

1. Open `docs/index.html` in your browser.
2. Use `Study` for review mode and `Mock Exam` for timed practice.
