Transformer Architecture

Core Pipeline

Input → Embedding + Positional Encoding → Multi-Head Attention → Add & Norm → Feed-Forward → Add & Norm → Output

Self-Attention Formula

Attention(Q, K, V) = softmax((QKT) / √(dk)) V

Q, K, V Matrices (MEMORIZE!)

  • Query (Q): The token seeking information ("what am I looking for?")
  • Key (K): Compatibility measure with other tokens ("what do I have?")
  • Value (V): The actual information to be retrieved ("the content")

Positional Encoding

  • Transformers process tokens in parallel (no inherent order)
  • Positional encoding injects sequence order information
  • Uses sine/cosine functions or learned embeddings

Key Components

  • Multi-Head Attention: Multiple heads focus on different types of relationships simultaneously
  • Residual Connections: Enable gradient flow in deep networks (skip connections)
  • Layer Normalization: Stabilizes training, enables deeper networks. Formula: LayerNorm(x) = γ × (x - μ) / σ + β
  • Feed-Forward Network: Applies non-linear transformations (2 linear layers + ReLU)
  • Softmax: Normalizes attention weights to sum to 1
  • Scaled Dot-Product: Divides by √d᮸ to prevent large values in softmax
Key Innovation over RNNs: Parallel processing capability — processes all tokens simultaneously

Training & Fine-tuning

Training Paradigms

  • Pre-training: Learning from massive unlabeled corpora (self-supervised)
  • Fine-tuning: Task-specific training on smaller labeled datasets
  • Transfer Learning: Leverages pre-trained knowledge → reduces time & compute

Parameter-Efficient Fine-tuning (PEFT)

  • LoRA: Adds small trainable matrices (low-rank adaptation)
  • Adapters: Small modules inserted between layers
  • Prompt Tuning: Optimizes prompts rather than weights

Key Concepts

  • Catastrophic Forgetting: Model loses pre-trained knowledge during fine-tuning
  • EDA: Essential to uncover patterns, anomalies, biases before fine-tuning
  • Teacher Forcing: Uses ground truth tokens during training (not model's own predictions)
  • Gradient Accumulation: Simulates larger batch sizes with limited memory
  • Learning Rate Warm-up: Gradually increases LR at start to stabilize training
  • Dropout: Randomly sets neurons to zero to prevent overfitting
  • Vanishing Gradient: Gradients too small during backprop → slow/stalled training

Tokenization

  • Tokenizer: Tool that splits text into smaller units (tokens) for processing
  • Subword Tokenization (BPE, WordPiece): Breaks words into subword units → handles OOV words
  • Reduces vocabulary size while maintaining semantic meaning

Generation Methods

  • Beam Search: Explores multiple candidate sequences simultaneously for higher quality
  • Nucleus Sampling (top-p): Samples from smallest token set exceeding cumulative probability p
  • Temperature: Controls randomness in generation (higher = more diverse)

Prompt Engineering

  • Zero-shot: Task description only, no examples
  • Few-shot: Provide a few examples in the prompt (no fine-tuning needed)
  • Chain-of-Thought (CoT): Step-by-step reasoning examples → best for complex multi-step reasoning
  • System Message: Sets role/context for contextually appropriate responses
For multi-step reasoning tasks: Chain-of-Thought prompting is the most effective technique

NLP Applications

  • NER: Extracts person, organization, location names from text
  • Extractive QA: Extracts answer span from passage
  • Generative QA: Generates new text as the answer
  • Sentiment/Emotion Classification: Use encoder models (BERT, RoBERTa)

RAG (Retrieval-Augmented Generation)

  • Combines information retrieval with text generation
  • Retrieves relevant documents, then generates grounded responses
  • Reduces hallucination, provides access to external/up-to-date knowledge
  • Chunking: Splitting text into meaningful segments for efficient retrieval

Model Optimization

Quantization

  • Reduces precision (FP32 → INT8) → smaller, faster, less power
  • Saves power and reduces heat
  • Reduces memory and improves cache utilization
  • Small trade-off in accuracy

Knowledge Distillation

  • Transfers knowledge from larger "teacher" to smaller "student" model
  • Student learns from soft probability outputs, not just hard labels

Deployment & Production

  • A/B Testing: Deploy both models, serve traffic equally (50/50) for fair comparison
  • Model Versioning: Enables seamless rollback and comparison
  • Docker/NGC Containers: Consistent environments for reproducibility
  • LangChain: Orchestrates LLM components into complex workflows
  • Cost Optimization: Balance performance, latency, and computational costs
  • Dynamic Batching (Triton): Combines requests for optimal throughput

Diffusion Models

  • Forward Diffusion: Progressively injects noise into data
  • Reverse Diffusion: Learns to generate samples from noise vectors

Ethics & Alignment

  • Red-Teaming: Adversarial testing to identify biases, safety risks, harmful outputs
  • Accountability: Ethical implications, potential misuse, unintended consequences
  • Explainability: Explicable decision-making for societal alignment
  • Hallucination: Model generating plausible but factually incorrect information

Experiment Design

  • Paired t-test: Compare 2 models on same data (normal distribution)
  • Cross-validation: Evaluate model when no test set available
  • Stratified k-fold: Preserves class distribution for imbalanced datasets

Python Libraries

  • HuggingFace Transformers: Specifically designed for LLMs; integrates with PyTorch & TensorRT for GPU acceleration
  • LangChain: Orchestrates LLM workflows (prompts, retrieval, memory)
  • Regular Expressions (regex): Filter/select training data by keywords
